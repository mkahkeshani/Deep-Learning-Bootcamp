# 💻 روش استفاده

ابتدا Repository را Clone کنید:

```bash
git clone https://github.com/USERNAME/deep-learning-bootcamp.git
```

سپس محیط Python موردنظر خود را فعال کرده و وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

برای اجرای پروژه‌ها، Notebook مربوط به هر پروژه را در Jupyter Notebook یا JupyterLab اجرا کنید.
